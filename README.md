# SkySavings TechHub Website

Modern static business portfolio website for SkySavings TechHub.

## Structure

```text
skysavingTechhub/
  index.html
  README.md
  assets/
    css/style.css
    js/script.js
    images/logo.png
    images/projects/
```

## Features

- Responsive agency-style landing page
- Services, pricing, portfolio, testimonials, FAQ, and contact sections
- WhatsApp floating button and WhatsApp-powered contact form
- Dark/light mode toggle
- Animated counters, reveal animations, and hero canvas particles
- SEO meta tags, Open Graph tags, and schema markup
- GitHub Pages compatible with no build step

## Customization

- Phone and WhatsApp number: search for `2347081306993`
- Email address: search for `info@skysavingstechhub.com`
- Logo: replace `assets/images/logo.png`
- Portfolio cards: edit the project cards inside `index.html`

## Portfolio Images

Place the screenshots in `assets/images/projects/` using these exact names:

- `Genux.png`
- `subx.png`
- `skysaving.png`
- `peopeldesk.png`
- `leadmap.png`
- `booking.png`

The site already points to those files and will show a clean fallback design until the images are added.

Open `index.html` directly in a browser or serve the folder from any static host.
